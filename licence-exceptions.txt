# Reviewed licence exceptions (D-70). Read by scripts/licence-check.mjs.
#
# Format, one per line:
#   <go|npm> <package-or-module-prefix> <licence>  # reason
#
# The prefix matches the package name exactly or as a "/"-delimited path prefix
# (so "@fontsource-variable" covers its scope, and "argparse" does not cover
# "argparse-evil"). The licence must equal what the scanner reports, so a package
# that changes licence in a later version fails again and is re-reviewed.
#
# Every entry needs a reviewed reason. An entry is a decision, not a convenience:
# GPL-2.0-only, SSPL, BUSL and Commons Clause code must not be added here.

# --- Reviewed 2026-10-01 (plan 01-04), against the real production tree ---

# Geist and Geist Mono variable fonts, bundled as font files and served to browsers.
# SIL OFL 1.1 explicitly permits bundling and redistribution with software and applies to
# the font files only (data, not linked code), so it does not interact with the AGPL.
# Obligation: keep the OFL notice in the third-party notices (plan 26).
npm @fontsource-variable/geist OFL-1.1  # font data bundled with the SPA; OFL permits redistribution, notice kept
npm @fontsource-variable/geist-mono OFL-1.1  # same as above

# The next three arrive only through the shadcn CLI (a pinned `dependencies` entry
# approved at 01-01), which is build-time tooling that is never part of the SPA bundle
# or the shipped binary. They are permissive licences that carry attribution only.
npm argparse Python-2.0  # via shadcn > cosmiconfig > js-yaml; PSF-style permissive, GPL-compatible, tooling only
npm caniuse-lite CC-BY-4.0  # via shadcn > babel > browserslist; browser-support data, attribution only, tooling only
npm isexe BlueOak-1.0.0  # via shadcn > dotenvx > which; permissive, attribution only, tooling only
npm minimatch BlueOak-1.0.0  # via shadcn > ts-morph; permissive, attribution only, tooling only

# --- Reviewed 2026-10-01 (plan 01-08) ---

# Trusted-proxy aware client IP resolution (rightmost-trusted-range strategy), approved at 01-01.
# 0BSD (BSD Zero Clause) is a public-domain-equivalent permissive licence with no attribution
# requirement, OSI approved and compatible with the AGPL. The allowlist has no 0BSD entry yet.
go github.com/realclientip/realclientip-go BSD-0-Clause  # permissive, no obligations, AGPL-compatible

# --- Reviewed 2026-10-19 (plan 07-20), the Compose SDK's dependency tree ---

# The Docker Compose SDK (github.com/docker/compose/v5 v5.6.0, Apache-2.0) pulls these three modules in
# through buildkit. go-licenses prints "no license found" for them because each LICENSE file holds only the
# Apache License 2.0 notice ("Licensed under the Apache License, Version 2.0 ..."), 13 lines, and not the full
# text it matches against. The notice is read from the module cache at the pinned version and matches the
# upstream repository, so each is Apache-2.0, which may be included in an AGPL-3.0 work. The licence column
# is what the scanner reports (Unknown), as the rule above requires; a new version that changes its LICENSE
# file is re-reviewed.
go github.com/in-toto/attestation Unknown  # Apache-2.0 notice in LICENSE (v1.2.0); go-licenses cannot classify the short file
go github.com/in-toto/in-toto-golang Unknown  # Apache-2.0 notice in LICENSE (v0.11.0); go-licenses cannot classify the short file
go gotest.tools/v3 Unknown  # Apache-2.0 notice in LICENSE (v3.5.2); go-licenses cannot classify the short file
